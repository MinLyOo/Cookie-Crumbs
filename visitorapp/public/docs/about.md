# 📅关于网站

## 🍪 Cookie Crumbs · 游戏活动日历

本网站是一个专为《明日方舟》玩家打造的活动日历工具，旨在帮助玩家方便了解游戏活动的时间安排。

### 数据来源

- 活动图片及部分信息来源于 [PRTS wiki](https://prts.wiki/) [官方公告](https://ak.hypergryph.com/news)
- 日期预测参考 [罗德岛蜜饼工坊](https://space.bilibili.com/8412516)

### 关于网站

- 项目地址：[~~Cookie Crumbs · 游戏活动日历~~](https://github.com/)（未来计划开源）
- 聚合日历：未来计划将多个游戏的活动日历聚合到一个页面日历上
- 剧情时间线：未来计划将明日方舟的剧情用时间线和节点展示出来，帮助玩家了解游戏的剧情发展
